# Legacy material

This folder is for scripts, reports, and historical validation artifacts moved
out of `DownscalingMoistureModel`.

Suggested layout:

- `legacy/reports_from_DownscalingMoistureModel/`
- `legacy/soilmoisture_points_validation_from_DownscalingMoistureModel/`
- `legacy/weatherlink_scripts_from_DownscalingMoistureModel/`
- `legacy/model6_dense_validation_spiking_reference/`

Bulky generated rasters, raw downloads, and caches should generally be kept
outside git and referenced by path unless there is a specific reason to archive
them here.
